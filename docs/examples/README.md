# Example files

Original, synthetic fixtures used in the app screenshots. No recordings, personal
files, or live session data are included. These files use the project's MIT license.

- [Mermaid diagram](message-flow.mmd)
- [Image](orbit-study.png)
- [Audio: two-second chime](completion-chime.wav)
- [Video: four-second orbit loop](orbit-loop.mp4)

Regenerate the media with `npm run examples:media` (requires FFmpeg), then capture
the app with `npm run screenshots`.
