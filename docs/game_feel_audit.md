# 조작 반응 감수

기준: Android WebView / 손가락 조작 / 360 × 833 CSS px.
목표: 즉각성, 단단한 눌림, 안정된 읽기, 명확한 전송 확인.
S는 소스, R은 실행 확인, P는 사람이 느낀 평가다. 이번 작업에는 P 판정이 없다.

| 행동             | 감각                 | 반응                             | 피해야 할 오해                     |
| ---------------- | -------------------- | -------------------------------- | ---------------------------------- |
| 상태·기기 필터   | 즉시 선택            | 선택면·하단선, 결과 전환         | 숫자 눌림이 새 작업을 시작함       |
| 카드 열기·뒤로   | 공간의 연속성        | 상세 진입, 목록 위치·포커스 복원 | 다른 에이전트로 이동함             |
| 대화 읽기·갱신   | 안정된 읽기          | 기존 노드 유지, 새 메시지만 진입 | 폴링할 때 새 대화가 시작됨         |
| 지시 입력        | 입력을 따라오는 크기 | 높이 자동 조절, 전송 가능 상태   | 아직 입력하지 않았는데 전송 가능함 |
| 메시지 전송      | 접수와 완료의 구분   | 눌림 → 잠금·진행 → 서버 확인     | 버튼을 누른 순간 전달 완료         |
| 탭 이동·새로고침 | 정확한 대상 변화     | 선택 탭, 요청 중 회전            | 화면 장식이 끝나야 요청 시작       |

## 기준 상태

| 행동        | 조작·제어         | 움직임            | 접촉·물성 | 카메라·공간            | 상태·시각                       | 오디오·햅틱                |
| ----------- | ----------------- | ----------------- | --------- | ---------------------- | ------------------------------- | -------------------------- |
| 필터        | 적절 S            | 없음 S            | 부족 S    | 해당 없음              | 적절 S                          | 없음 S                     |
| 상세·뒤로   | 부족 S            | 없음 S            | 부족 S    | 부족 S: 복원 없음      | 적절 R                          | 없음 S                     |
| 읽기·갱신   | 부족 S: DOM 교체  | 의도적 절제       | 해당 없음 | 부족 S: 읽기 연속성    | 적절 R                          | 의도적 절제: 폴링은 무음   |
| 입력        | 적절 S            | 부족 S: 고정 높이 | 부족 S    | 부족 S: 키보드 공간    | 적절 S                          | 의도적 절제: 키보드에 맡김 |
| 전송        | 적절 S: 중복 차단 | 없음 S            | 부족 S    | 해당 없음              | 부족 S: 완료 문구가 즉시 지워짐 | 없음 S                     |
| 탭·새로고침 | 적절 S            | 없음 S            | 부족 S    | 부족 S: 전환 방향 없음 | 부족 S: 요청 중 표시 없음       | 없음 S                     |

카메라는 게임 시점이 아닌 화면과 스크롤을 뜻한다. 충돌·이동 규칙은 해당하지 않는다.

## 우선순위

- P1: 4초마다 목록을 다시 만드는 경로를 줄인다. 검색 포커스·카드 노드·대화 노드를 보존한다.
- P1: 상세 진입과 복귀를 연결하고, 빠른 대상 전환에서 마지막 대상 요청을 이어 간다.
- P1: 입력·전송 중·전달 확인·거부를 전송 버튼과 입력란 가까이에서 구분한다.
- P2: 중복 경로·제목·턴 수·항상 보이던 글자 수를 걷어내고 각진 면과 상태 대비를 적용한다.

## 확인 범위

기준 앱의 실제 목록과 연결 상태를 확인했다. 초기 ADB 캡처는 사용 중 홈 화면이 찍혀 비교 근거에서 제외했다. WebView 캡처는 `artifacts/design-before-web.png`, 기준 rAF 표본은 120개다. 화면에 보인 사실과 코드로 확인한 내용을 구분한다.
